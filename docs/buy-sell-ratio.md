# 买卖比异常值处理设计

## 问题

当前买卖比直接计算平台加权后的 `buy_ratio / sell_ratio`。当当天没有观察到卖出帖子时，除零保护会把结果写成 `99.9:1`，把“样本中没有卖出”误读成“卖出概率为零”。小样本下，这个结论不成立。

## 决策

采用对称中性先验平滑，而不是读取近期历史均值：

```text
平滑买卖比 = (平台加权买入占比 + 1) / (平台加权卖出占比 + 1)
```

- `1` 是与两侧对称的中性基础值，避免任一侧为零时除零。
- 两边都没有买卖信号时仍返回 `0.0`，表示“无买卖信号”，不伪造 `1:1`。
- 该公式同时处理“接近零”的分母，避免只有极少数卖出样本时再次出现极端值。
- 平台权重和现有买入/卖出指数保持一致；不引入历史文件依赖，也不改变原始计数。

在当前占比取值范围内，单边全为买入时结果最多为 `2.0:1`，单边全为卖出时为 `0.5:1`，足以表达方向但不再表达虚假的无限确定性。

## 展示与验收

- 网页和飞书继续展示平滑后的 `buy_sell_ratio`。
- 没有买入和卖出信号时，网页显示“无买卖信号”；飞书沿用现有的“无买卖信号”文案。
- 覆盖：买卖都有、仅买入、仅卖出、无小白、全观望五类场景。

## 开发记录

- 仓库当前未配置 pytest 的导入路径；从仓库根目录直接执行 `pytest` 会在收集阶段找不到 `analyzer`、`collectors`、`scripts`。验证使用 `PYTHONPATH=. pytest ...`，不修改与本需求无关的测试配置。
