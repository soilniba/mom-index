# LLM 语义分类器（deepseek-v4-flash，仅小红书）

用 DeepSeek 语义分类替换**小红书**帖子的关键词判定，解决关键词无法区分
「散户小白求助」与「博主教学/攻略内容」的系统性误判。
股吧保留关键词规则（短标题情绪帖为主，LLM 无正文时幻觉风险高，
实测收益小）——按 platform 字段在 analyze_all 中分流。

## 配置

```bash
~/.config/mom-index/env   # 与 XHS_COOKIE 同文件
export DEEPSEEK_API_KEY='...'
export DEEPSEEK_OPENAI_URL='https://api.deepseek.com'
export LLM_MODEL='deepseek-v4-flash'
```

定时任务（systemd）无 shell 环境，故 key 必须存在 env 文件（git 外）。
未配置 key 时自动回退关键词规则，不影响采集。

## 工作方式

1. `pipeline.py → analyzer/llm_analyzer.analyze_all`
2. 按 platform 分流：xiaohongshu → LLM；guba → 关键词规则
3. 小红书帖子分批（30 条/批）发给 deepseek-v4-flash，返回每条的
   `newbie_score`/`sentiment`/`intent`/`reasoning`/`key_signals`
4. level/置信度本地推导（与指数公式阈值 >=20 小白、>=50 纯小白对齐）
5. 任何失败（无 key/网络/解析）→ 小红书部分回退关键词规则
6. 同一批小红书帖子同时跑一份关键词规则，分歧写入
   `data/ab_test/YYYY-MM-DD.jsonl` 用于量化 LLM 提升

## 为什么值得做（实测对比，2026-08-03，80 条小红书抽样）

关键词规则的两类实质误判：

| 误判类型 | 示例 | 规则判定 | LLM 判定 |
|----------|------|----------|----------|
| 教学帖当小白（系统性，指数虚高） | 「新手小白买黄金必看攻略」 | 偏小白 42 | 专业 5-10 |
| 教学帖当小白 | 「刚入行半导体｜先听懂10个词」 | 偏小白 42 | 专业 5 |
| 短句情绪帖漏判（随机） | 「企稳了吗」 | 偏专业 18 | 纯小白 85-90 |
| 短句情绪帖漏判 | 「cpo下周还会📉吗」 | 偏专业 18 | 纯小白 75-85 |

教学帖误判是**系统性**的：主题越火→攻略帖越多→指数越虚高，聚合后不抵消，
会滞后于真实小白情绪拐点。这是换 LLM 的核心原因。

## 稳定性与成本

- 温度 0 + 正反例判别口诀后，关键案例两轮判定一致；剩余抖动集中在
  语义本身模糊的边界帖（打卡/学习笔记/短标题），约 7% 跨阈值，
  聚合层面相互抵消
- 成本：~30k token/天 ≈ 0.1 元/天（每日 23:30 一次，仅小红书 4 批）
- 耗时：~4-5 分钟/次（4 批请求，每批 ~60s）

## 注意

- LLM 调用失败会静默回退关键词规则（不告警）——A/B 日志可观察回退发生
  （当日文件无 LLM 结果行即回退）
- 股吧不调 LLM：无正文时 flash 会编造不存在的上下文（实测出现
  "我买点看看能不能赚钱"被判"专业债市收评"的幻觉），且实测收益小
- 模型列表变化时核对 `DEEPSEEK_API_KEY` 权限下的可用模型
