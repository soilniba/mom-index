# 沪深300 ETF配置强度代理（2026-10-31）

状态：用户已批准修订方法；本页取代旧四只ETF/普通流通市值口径的运行设计。

## 目的与口径

间接观察国家队相关配置阶段，不精确识别其账户持仓或每日买卖。
主指标为全部普通被动沪深300 ETF的同日份额×单位净值，除以当日有效300成分股的
收盘价×自由流通股本之和，再乘100，以百分比展示。
增强、联接、杠杆/反向等产品排除；上市日起纳入，退市日起移除。
分子和分母由stock_data具名接口统一计算，本项目不再自己选四只或请求普通流通市值。

方法依据：[光大2024-12-25《A股资金结构分析框架》2.3节](https://finance.sina.com.cn/stock/stockzmt/2024-12-26/doc-ineauuyr6705046.shtml)。
研报未提供逐只名单，不声称与其26只样本精确相同。指标含其他投资者，分红、调样等
也可能影响比例；比例变化不能单独确认国家队买卖。

## 数据与版本隔离

- 仅调用`stock_data.fetch_csi300_etf_position_history(YYYYMMDD, YYYYMMDD)`。
- 使用`methodology_id=csi300_etf_free_float_v1`，独立保存`data/csi300_etf_position.json`。
- 保留旧`etf_oi.json`为旧口径，不读入、拼接或覆盖旧数据；版本不同拒绝增量合并。
- 首版请求自2024-01-01起的已核验历史；接口明确返回其覆盖边界，不外推有效成员。
- 重拉最近45自然日窗口吸收修订，硬失败或整个窗口无完整值时不覆盖已存文件。
- 必要事实缺失时保留空比例，图中断线；指数点位或成交量缺失不阻止比例展示。
- 源新返回的缺口替换同日旧值，不用陈旧比例掩盖当前不完整事实；只在整个刷新失败时保留旧文件。
- 成功更新后原子发布同一新文件到`frontend/data/`；发布失败保留前端旧文件。

## 展示与发送

- 名称统一为“沪深300 ETF配置强度代理”，展示最新完整日、当日样本数量、全部规模和自由流通市值。
- 沿用双轴曲线、成交量、最近250交易日窗口与原23:30发送顺序，不增加页面、依赖或交易信号。
- 图片或行情不可用仍可展示比例数值；网页只接受新版本数据。
- 验证只更新或本地预览，不向飞书发送消息。

## 验收与记录

- 更新器真实调用共享API，记录动态样本和新分母；旧文件、错误版本、硬失败均有保护测试。
- 源返回缺口不填零、不跨日补净值；PNG/网页缺口不连线。
- 图卡和网页不再出现固定四只、普通流通市值或确认国家队持仓的表述。
