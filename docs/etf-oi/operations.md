## 手动命令

在仓库根目录使用 `/home/wangr/venvs/py314/bin/python`：

```bash
# 只更新新增指标，不发送
python scripts/notify_etf_oi.py data --update-only
# 更新并本地预览，不发送
python scripts/notify_etf_oi.py data --preview /tmp/etf-oi.png
# 仅发送缓存的新增指标
python scripts/notify_etf_oi.py data --no-refresh
# 先发完整宝妈报告，再更新并发送新增指标
python -m scripts.daily_reports data
```

每日任务保持北京时间23:30运行 `pipeline.py`；通知阶段调用 `scripts.daily_reports.send_reports`，严格串行。
指标更新失败时旧历史不覆盖，卡片标注失败与截至日；绘图/上传失败仍发数值。临时上传PNG随上下文自动删除。
