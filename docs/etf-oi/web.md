# 网页底部同步展示

日期：2026-10-28。用户要求：“在妈宝指数的网页上也同步加上这个指数，加到底部”。

本页为旧四只口径网页设计；当前文件、公式、样本与展示以[修订方案](position-proxy.md)为准。

## 最小设计

- 在原四板块曲线及今日帖子之后、页脚之前追加一个完整宽度的指标区。
- 与飞书共用 `data/etf_oi.json`，发布到 `frontend/data/etf_oi.json`；保留2023年起历史，默认只画最近250个交易日。
- 复用网页已有本地 Chart.js：上方占比（金色，左轴%）与沪深300（蓝色，右轴点位），下方同日期成交量（亿股）。
- 收盘高于昨收用红柱，低于昨收用绿柱，平盘/缺昨收为灰柱；缺数据保持空点，不连接比例缺口。
- 展示最新完整日、占比、四只规模、指数市值及样本口径；较新行情缺规模时明确说明。数据加载失败只影响新增区域。
- 沿用原样式与移动端布局，不新增依赖、服务、筛选器或新页面。

## 实现选择

采用已有 Chart.js 交互图，便于按日期查看点值；PNG已用于飞书，网页直接读取同一份JSON可避免额外图片发布链路。此为实现判断。

更新与单独补齐时同步发布ETF数据，防止网页落后于飞书。手动 `sync_data.py` 也包含新文件。发布失败保留旧前端文件，不打断原宝妈报告。

## 验证与实施步骤

1. 先更新需求与本设计；独立修改网页展示和数据同步。
2. 验证更新后网页读到新数据、同步失败不破坏旧文件，保留既有推送顺序。
3. 浏览器实际检查桌面/手机布局、双轴、红绿柱、缺口和数据失败状态；原四板块继续可用。
4. 更新运维记录，完成测试、安全审查、中文提交与推送。
